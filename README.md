# Eden Syntax Highlighting Extension

This extension provides syntax highlighting support for the **Eden** language. 

Currently, the extension focuses on adding syntax highlighting for Eden code. In the future, this extension will include a built-in Eden interpreter, enhancing its functionality.

## Links
- Eden syntax repo: [Eden-lang-ext](https://github.com/DarekKrawczyk/Eden-lang-ext)
- Eden language repo: [Eden](https://github.com/DarekKrawczyk/Eden)

## Features
- Syntax highlighting for the initial version of the Eden language.
- More features planned, including an integrated interpreter.
