# Change Log

## Version 1.0.1
- Minor bugfixes on initial release version.

## Version 1.0.2
- `Literal` and `As` are now recognized and highlighted as language keywords.
- Updated the variable regular expression to correctly detect the last variable in an expression. For example, in `Pi * 3.14f * Pi`, the final `Pi` is now properly identified.
- Modified the `Keywords` color in the Eden color theme.
